# Responsible use of LLMs

LLMs can support learning and research workflow. They do not replace reading, data work, judgment, or responsibility for submitted work.

## Permitted support

- brainstorming and narrowing research questions;
- explaining difficult passages or concepts;
- generating search terms;
- coding assistance and debugging;
- feedback on outlines, figures, tables, and slides; and
- language correction when permitted by the instructor.

## Not permitted

- submitting AI-generated prose as your own final paper;
- inventing references, results, or data work;
- using a summary instead of reading an assigned paper;
- uploading protected, personal, or restricted data; or
- concealing material AI assistance.

## A reliable workflow

1. State the task, context, constraints, and desired output.
2. Ask the model to challenge your design, not only improve it.
3. Verify claims against the original paper, data, code output, or official source.
4. Test generated code yourself.
5. Keep a short record of material assistance.

## Learning to code with AI

Use AI as a patient coding tutor, code reviewer, and debugging partner. Do not use it as a copy-paste machine.

### Better prompts

- “Here is my R code and the error. Do not give me the fixed code immediately. Ask me questions that help me diagnose it.”
- “Explain what this code does line by line, then ask me to predict what will happen if I change this variable.”
- “Review this regression code for an error in the sample, treatment definition, fixed effects, or standard errors.”
- “Give me a minimal example that demonstrates this error. I will write the solution first.”
- “Act as a skeptical coauthor: what checks would you require before believing this result?”

### Avoid this pattern

Do not paste an assignment or error message and submit the first working-looking answer. Run the code, inspect the output, explain the logic in your own words, and change one component yourself before relying on it.

Eric J. Ma’s [How AI turbocharges your learning](https://ericmjl.github.io/blog/2026/7/27/ai-turbocharges-learning/) is the recommended companion reading. Its practical message is simple: use AI to retrieve, defend, test, and improve your thinking; do not let it replace the thinking.

## AI-use appendix

For each substantial use, record the tool/model, purpose, important prompt or workflow, what you retained or rejected, and how you verified the output. You remain responsible for every claim, citation, result, and line of submitted code.
