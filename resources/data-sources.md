## Responsible web data

Use web data only when the source is public and its terms permit the use you intend.

1. Read the website terms and `robots.txt`; do not scrape logins, paywalls, or personal data.
2. Record the source URL, retrieval date, filters, and code used to download or collect data.
3. Save the raw download and metadata unchanged; analyse a separate cleaned copy.
4. Check definitions, denominator, units, missing values, and changes in classification before making a figure.
5. Cite the provider and the exact version/date. A screenshot is not a data citation.
6. Bring any uncertain web-data idea to the data-feasibility checkpoint before collecting at scale.
